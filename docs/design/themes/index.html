Ten ways to paint your home screen.

Every deck keeps the Paint Chip skeleton: a colour field, an ivory label band with all the words, and a die-cut punch hole. Each one swaps the five section paints, the display font, how round the corners are and the shape of the punch hole. Pick one below; all three phones switch. Every deck is free.

The catalogue

Built for a 16–20 crowd with different tastes: loud and cartoony, calm and oceanic, bookish, cosy café, gamer, Y2K, sporty, starry and lo-fi. Paint names on the band change with the deck, so a class chip reads "Hot Sauce · BIO 201" in Saturday Cartoons.

What stays the same

Layouts, body text (SF), condensed caps labels, the two-sizes-per-chip rule, no text on colour fields, no gradients or glass. Someone who can read one deck can read them all.

Accessibility

Every deck passes WCAG AA for all text: ink on the band is at least 14:1 and caps labels at least 4.6:1. Dark paints (Tech, Evening) stay dark so fill bars and mood keys keep 3:1 or better. The tests check this for every deck.

How it ships

Picked in onboarding step 1 and in Settings → Theme. The choice is stored in the App Group, so widgets redraw in the same deck. Theme Sync can still recolour a deck from a wallpaper; the deck's font and shapes stay.
